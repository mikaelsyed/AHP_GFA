# AHP_GFA

Hi, this project applies Analytic Hierarchy Process (AHP) to generate a flood susceptibility model using geospatial data. The model evaluates Topographic Wetness Index (TWI), Elevation, Slope, and Floodplain Proximity. Weighted criteria is derived through a pairwise comparison and consistency assessment. All calculations, including matrix normalization, weight derivation, and consistency metrics, were done in R and documented in an R Markdown file.
